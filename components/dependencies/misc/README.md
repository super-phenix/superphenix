# misc

![Version: 0.0.0](https://img.shields.io/badge/Version-0.0.0-informational?style=flat-square)  ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square)  ![AppVersion: 0.0.0](https://img.shields.io/badge/AppVersion-0.0.0-informational?style=flat-square)

A helm chart to deploy arbitrary YAML objects.

Objects are rendered as Helm templates before being applied.

Objects not listed in `modes`, or mapped to an empty list, are deployed in every effective mode. A non-empty list restricts an object to modes matching the `effectiveMode` value.

## Example

```yaml
objects:
  my-configmap:
    apiVersion: v1
    kind: ConfigMap
    metadata:
      name: my-configmap
    data:
      cluster: '{{ .Release.Name }}'
modes:
  my-configmap:
    - DecoupledStorage
```
